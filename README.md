# 🛠️ Coding Temple Full-Stack Software Engineering Workshops

This repository serves as a dedicated collection for all supplemental workshops completed during the Coding Temple Full-Stack Software Engineering certification program.

## Overview and Purpose
While the main portfolio demonstrates comprehensive, full-scale applications, this repository is focused on targeted skill development and deeper dives into specific technologies or complex programming concepts.

Each directory represents an isolated workshop or challenge, allowing for quick review and iteration on fundamental techniques outside the scope of the major capstone projects.
